# 彩票 AI 数据分析助手（Streamlit）

支持：**双色球 · 快乐8（官方）· 极速飞艇 · 极速快乐8**

> 仅供学习娱乐。开奖随机，历史统计不能预测未来。

## 功能概览

| 彩种 | 功能 |
|------|------|
| 双色球 | 频率/遗漏/和值、五码组合历史对照 |
| 快乐8（官方） | 频率/遗漏/和值奇偶、五码对照 |
| 极速飞艇 | 实时开奖、自动刷新、名次热力、冠亚和、龙虎、**大小/单双路珠**、**每期自动对照下期比例** |
| 极速快乐8 | 实时开奖、和值**大单/大双/小单/小双**、5期组合自动对照、会话缓存路珠 |

## 运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

浏览器打开 http://localhost:8501

## 数据源

- 双色球 / 官方快乐8：`data.17500.cn`
- 极速飞艇：`api.api16868.com/pks`（lotCode=10037）
- 极速快乐8：`api.api16868.com/LuckTwenty`（lotCode=10047）

## 上传 GitHub / Streamlit Cloud

只需上传：

- `app.py`
- `requirements.txt`
- `README.md`

不要上传 `data/`、`__pycache__/`。

## 说明

路珠与「自动对照」给出的百分比是**历史条件出现比例**，不是下一期真实概率。
